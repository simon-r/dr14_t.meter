Manual page - dr14_tmeter (1)

NAME

dr14_tmeter - compute the DR14 value of the audio files according to the algorithm described by the Pleasurize Music Foundation. Visit: http://www.dynamicrange.de/

HOMEPAGE

https://github.com/simon-r/dr14_t.meter

SYNOPSIS

dr14_tmeter [OPTIONS] [PATH]

DESCRIPTION

DR14 T.meter is a free and opens source command line tool for computing the Dynamic Range of your music according to the procedure used in the off-line meter released by the Pleasurize Music Foundation.

This tool is very useful to measure how is loud your music and for understanding that a good quality album always has also a good dynamic, and it's also useful for understanding the effects of the so called loudness war.

OPTIONS

-h, --help

Show the help message and exit.

Input and scanning

PATH

File or directory to analyze.

-r, --recursive

Scan recursively the subdirectories.

-f, --file

Compute the DR14 of a single file and exit.

--files_list

Take a files list and compute the DR of each file; if no files are specified, it reads from STDIN.

Output files

-o, --outdir OUT_DIR

Write the resulting files into the given directory.

-t, --tables {h,t,b,w,a}

Select the output files to be written. h=html t=text b=bbcode w=mediawiki a=all_formats.

-b, --basic_table

Write the resulting tables in the basic format.

-a, --append

Append all results in a single file; it should be used in couple with -r.

-n, --turn_off_out

Do not write the output files.

--no_overwrite

Skip the directories that already contain the selected output files (e.g. dr14.txt); useful with -r for analyzing only the new albums.

-p, --print_std_out

Write the full result on the std_out.

-d, --dr_database

Output file compatible with the DR database at https://dr.loudness-war.info/

--tag

Write the DR to the tag of the input files.

Performance and verbosity

-1, --disable_multithread

Disable the multi-Core mode.

--quiet

Quiet mode.

Local database

--enable_database

Enable and create, if necessary, the local DR database.

--disable_database

Disable the local DR database.

--dump_database

Dump the local DR database.

-q, --query [QUERY ...]

Query the database. Options: [-q] [-q top #nr] [-q worst #nr] [-q top_alb #nr] [-q worst_alb #nr] [-q top_art #nr #mt] [-q artist "name" #nr] [-q album "name" #nr] [-q hist] [-q evol] [-q codec] [-q info] [-q genres #nr] [-q help]

Single-file analysis and plots

--hist

Plot the histogram of dynamic of a single file and exit.

--lev_hist

Plot the histogram of the samples levels of a single file and exit.

--spectrogram

Plot the spectrogram of a single file and exit (beta).

--plot_track

Plot the track of the given file and exit.

--plot_track_dst

Plot the track in a cool manner of the given file and exit.

--dyn_vivacity

Plot the graph of the dynamic vivacity of a single audio file and exit.

--compress {very_soft,v,soft,s,medium,m,hard,h,very_hard,vh}

Perform the dynamic compression on a single file and exit; the resulting track will be written in a temp directory.

Miscellaneous

--skip_version_check

Do not check for new versions.

-v, --version

Print the current version and exit.
