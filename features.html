Features list

  • Computes the DR dynamic range of audio files, with identical results to the official offline meter
  • Reads FLAC, MP3, Ogg Vorbis, Opus, MP4/M4A, WAV, WavPack, AC3, WMA, DSF and DFF
  • Multi-core computation (half of the cores by default)
  • Scans a directory, or recursively a whole music collection
  • Measures a single file or a list of files (also from standard input)
  • Writes the results as text, HTML, BBCode or MediaWiki tables, also compatible with the DR database
  • Uses the audio metadata for generating the tables
  • Optional local SQLite database of all your results, with queries: best and worst tracks, albums and artists, DR per year and per codec, collection summary, in an interactive terminal menu
  • Writes the DR values into the tags of FLAC, Ogg, Opus, MP3 and MP4 files
  • Plots: histograms, waveform, spectrogram and dynamic vivacity of a single track
  • Dynamic compression of a single track (very soft to very hard)

See How to use for the details.
